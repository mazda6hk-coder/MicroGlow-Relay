# Theme preview sources

These six PNGs are native Qt captures of MicroGlow Relay's existing dashboard,
using isolated empty synthetic data, no requests and no real Codex configuration.
Generated on 2026-10-06 with `work/capture-settings-reference-20261006.py --thumbnails`.
They are static illustrations of the actual palettes, not live user screenshots.
MicroGlow is intentionally shown as its actual dark teal theme, rather than the
light thumbnail in the supplied layout reference. No telemetry consent was granted.

The settings palette glyph is the standard Lucide `palette` icon:
https://github.com/lucide-icons/lucide/blob/main/icons/palette.svg (ISC).
