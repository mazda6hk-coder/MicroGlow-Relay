# MicroGlow Relay 隐私政策

版本：1.0 · 生效日期：2026年10月7日

郑州微光智能科技中心提供 MicroGlow Relay。本政策说明当前版本的数据处理，不授权超出下述范围的处理。

## 软件运行与本地数据

Relay 不要求注册账号。你填写的供应商、模型、接口地址和连接凭证保存在本机；当前 Windows 版本使用 Windows DPAPI 加密保存 API Key 和本地访问令牌。

为完成模型调用，Relay 会在本机处理请求，并将调用所需的对话内容、工具数据和凭证发送到你选择的模型服务。第三方接收的数据受其自身条款和隐私政策约束，这与下面的可选使用统计是两条独立链路。

修复会话会读取必要的会话列表与接入配置，并调整你选定会话的接入方式，不为使用统计上传会话列表或对话正文。配置恢复可能在本地生成备份与恢复凭据。

本地请求记录含时间、供应商名称、模型、状态、耗时、输入和输出 Token 数，以及标准错误类别；旧版本文件可能含脱敏的错误摘要。本地使用记录载入最近30天、最多20,000条，但原文件不会因此自动清空。实时事件日志在内存中最多保留600条。本地诊断文件可能记录固定错误代码。

为支持工具调用轮次的多轮续接，Relay 会在本地缓存上游返回的推理文本，最长 7 天、最多 2000 条；该缓存仅在本机，不随匿名统计上传。

## 可选使用统计：默认关闭

接受用户协议不等于同意上传统计。安装页“同意加入（推荐）”和“不同意加入”均不预选，你需主动选择一次才能继续；不会再次弹出遥测确认窗口。选择同意并完成安装，或在设置中主动开启并确认统计说明后，才授权统计及上传；选择不同意则关闭统计及上传。拒绝不影响安装和软件使用；首次静默安装不授权统计，静默升级保留已有授权状态。关闭后停止新增使用统计和上传，不影响模型调用，也不会自动删除已留存的本地汇总。

统计用于了解模型使用与调用质量。新批次包含的字段为：随机安装标识、批次标识、统计协议版本、授权版本与授权状态、Relay版本、UTC统计日期、供应商类别、模型名称或模型系列、官方/中转/未知调用渠道分类、活跃分钟、调用次数、成功次数、错误次数、输入Token数、输出Token数、总Token数、固定耗时区间计数（小于1秒、1至3秒、3至10秒、至少10秒）、标准错误类别计数（认证失败、频率限制、超时、服务不可用、请求无效、其他）和回退次数。

新批次不采集系统类别。升级前已封存的待上传批次可能仍带旧系统字段；为维持批次一致性，重试不会改写该批次。随机安装标识用于去重和连续统计，并非姓名；服务器以散列标识保存关联信息，不能把这种关联统计理解为完全不可关联的数据。

客户端只在正常退出时尝试上传待处理批次，包括托盘“退出”；关闭到托盘不会触发退出上传。只有收到匹配的成功确认才标记批次完成；失败或拒绝保留，下次正常退出再尝试。已确认批次的本地存储目前没有自动删除期限，关闭统计也不自动清理。

国家/地区仅根据网络连接在服务器端进行粗略判断，客户端不会读取或上传定位信息。网络通信必然向接收端暴露来源地址；遥测汇总数据库不将原始IP作为统计字段保存。统计字段不含实际接口地址或逐请求正文。

## 更新、反馈与保存

软件启动后及运行期间每24小时会在后台检查更新，也可在设置中手动检查。更新检查优先连接GitHub公开发布接口，失败时连接官网备用清单；发现新版本后自动下载并校验安装包。相关网络服务会接收到建立连接所必需的网络信息；更新请求不附带随机安装标识、模型配置、凭据、会话正文或匿名使用统计。安装必须由用户主动操作，不会自动执行。打开官网或邮件链接会交由相应浏览器或邮件程序处理。更新检查与匿名统计授权独立。

复制诊断信息仅在你主动操作时进行，包含版本、Build、Windows版本、架构、监听端口和数据/日志目录。目录可能带有Windows用户名，请在发送前检查。你主动发来的邮件和附件将用于处理对应反馈，不应包含密钥或无关的对话、文件。

本地数据及服务端汇总目前没有统一自动删除期限。你可关闭统计；需要清理本地数据时先正常退出并备份，再按帮助指引处理。卸载程序不自动删除用户数据。服务端关联数据的访问、更正或删除请求，请联系下述邮箱；我们按适用法律处理，不承诺能够识别无法关联到你的汇总记录。
