# MicroGlow Relay 使用帮助

## 接入

1. 在“模型”页填写供应商接口地址、API Key，并添加模型。
2. 正常退出 Codex 桌面端和命令行，开启 Relay，等待服务就绪，按提示开启 Codex 接入。
3. 重新启动 Codex。Claude Code 使用对应的接入开关，按提示操作。

关闭 Relay 或正常退出程序会恢复原生 Codex 接入。缩到托盘不等于退出，请使用托盘菜单的退出命令。

先退出 Codex / Claude Code，再退出 Relay，接入配置会自动恢复。若恢复失败，Relay 会保持运行并提示原因；处理后再次退出即可。

## 模型与会话

- 在 Codex 会话内按需选择模型；默认模型在“模型”页设置。该页支持新增、编辑、搜索、删除配置，并为同一模型添加多个渠道。
- 配置中的模型名称与 Codex 原生模型名称完全相同时，对应条目会出现在 Codex 的模型选择器中。例如保存模型名为 `gpt-6-astra` 的配置后，该条目出现；删除最后一条提供该模型的配置后，条目消失。没有对应配置的名称不会列出。
- 原生条目经 Relay 转发到第三方接口时可继续对话，但会移除加密推理内容，第三方收到推理摘要与文本。OpenAI 的加密内容只有 OpenAI 能读取。如需保留加密推理链，请使用接口为 `api.openai.com`、配置您本人 OpenAI 密钥的渠道。
- 会话接续只调整所选会话的接入配置，不改写历史对话。操作前按提示正常退出 Codex。
- 双向切换的步骤一致：退出 Codex 桌面端和命令行，选择会话及目标，然后应用。不要求 Codex 正在运行或已登录，也不要求 Relay 已开启；转入 Relay 前需保存模型配置。
- 转回官方接入时，优先参考最近可用的官方会话模型；没有参考时，使用该会话原始官方元数据备份。两者均无可靠来源时，转换停止。
- 转换后，Relay 接入需先开启 Relay 再启动 Codex；官方接入需先关闭 Relay 再启动 Codex。使用官方服务时，Codex 仍可能要求登录。

## 常见问题

### 没有模型？

首次安装没有预置模型。请添加自己的供应商和模型；“获取可用模型”支持多选，每个模型保存为一条配置。

### 请求失败？

检查接口地址、密钥、余额和模型名称。反馈不要发送密钥或对话正文。

### Token 统计从哪里来？

来自原请求上游响应中的用量信息，不会为不同展示位置重复请求。

### Trip Token A/B 如何使用？

A、B 是两段独立小计，从各自的清零时刻开始，按所选范围统计。跨日不清零，重启后继续，只有该栏的“清零”会重置。清零不改变今日总量和请求日志，会将原区间存入行程记录。可分别记录两个任务并命名。失败请求仍计入请求次数；Token 按上游返回的用量统计。

### 如何筛选日期？

选择日期及日、周、月、季、年周期，查看对应时间范围的数据。错误比例的分母是所选范围的总请求数。

### 匿名统计如何授权？

安装页的“同意加入”和“不同意加入”均不预选，主动选择一次后继续。选择同时控制本地匿名统计和上传授权，不重复确认；拒绝不影响安装和使用，可在设置中更改。首次静默安装默认关闭，静默升级保留已有授权。仅正常退出时尝试上传，失败后下次退出重试。完整字段与保存行为见隐私政策。

### 如何更新？

开启自动检查更新时，Relay 在启动后及每 24 小时后台检查，优先使用 GitHub，官网作为备用源。新安装包自动下载并校验大小和 SHA256。点击设置中的“安装更新”打开安装器，安装前正常退出 Relay。安装器不会自动执行；也可点击“立即检查”手动检查。

### 数据与卸载

设置页显示数据目录，卸载保留用户数据。如需清理，先正常退出 Relay，备份需要保留的内容，再处理该数据目录。不要删除 Codex 目录。
