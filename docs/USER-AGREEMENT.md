## 1. 产品说明

Relay 是一款帮助用户连接、配置和使用人工智能模型服务的桌面软件。

当前版本主要面向 Windows 平台及受支持的 AI 客户端工具，提供模型服务配置、连接管理、模型切换、请求管理及会话接续等功能。

Relay 本身并非人工智能模型提供商。除非产品界面或相关服务条款另有明确说明，用户通过 Relay 配置和使用的第三方模型服务，由相应第三方服务提供商提供。

Relay 可能需要你自行配置第三方模型服务的 API 密钥、访问令牌或其他连接凭证。

你应妥善保管自己的第三方账户和凭证，不应向无关人员泄露。

Relay 对凭证的具体存储和处理方式，以当前版本的实际实现和相关产品说明为准。

如果你怀疑自己的第三方 API 密钥或账户凭证已经泄露，应及时通过相应服务提供商提供的方式撤销或更换凭证。

## 6. 会话接续及配置修改

Relay 的部分功能可以通过调整受支持客户端的模型服务配置，帮助用户在不同模型服务之间继续已有工作。

由于不同客户端、模型、模型版本及第三方接口之间可能存在能力、上下文长度、工具调用、参数格式和输出行为等差异，切换模型服务后产生的结果可能与原模型不同。

Relay 不保证不同模型之间具有完全相同的行为，也不保证所有第三方客户端未来版本始终与当前版本保持兼容。

涉及客户端配置修改时，我们将尽合理努力避免损害用户已有配置和数据。用户仍应对重要项目、配置和数据保持适当备份。

MicroGlow 可以根据产品维护、安全、兼容性及功能改进需要发布 Relay 更新。

对于影响正常使用的重要兼容性问题，我们会根据实际情况提供修复、更新或相关说明。
