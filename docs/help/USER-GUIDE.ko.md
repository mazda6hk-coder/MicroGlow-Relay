# MicroGlow Relay 사용 도움말

## 연결

1. 모델 페이지에서 공급자 주소와 API 키를 입력하고 모델을 추가합니다.
2. Codex 데스크톱 앱과 명령줄 프로그램을 정상 종료합니다. Relay를 켜고 서비스가 준비되면 안내에 따라 Codex 연결을 활성화합니다.
3. Codex를 다시 시작합니다. Claude Code는 해당 연결 스위치를 사용하고 화면 안내를 따르세요.

Relay를 끄거나 정상 종료하면 Codex의 기본 연결로 복원됩니다. 트레이로 최소화하는 것은 종료가 아닙니다. 트레이 메뉴의 종료 명령을 사용하세요.

Codex / Claude Code를 먼저 종료한 다음 Relay를 종료하세요. Relay는 종료 전에 연결 설정을 복원합니다. 복원에 실패하면 종료하지 않고 이유를 표시합니다. 문제를 해결한 후 다시 종료하세요.

## 모델과 세션

- Codex 세션 안에서 필요한 모델을 선택합니다. 기본 모델은 모델 페이지에서 설정합니다. 이 페이지에서 구성을 추가, 편집, 검색, 삭제하거나 같은 모델에 여러 채널을 추가할 수 있습니다.
- 저장한 모델 이름이 Codex 기본 모델 이름과 정확히 일치하면 해당 항목이 Codex 모델 선택기에 나타납니다. 예를 들어 모델 이름이 `gpt-6-astra`인 구성을 저장하면 해당 항목이 표시됩니다. 그 모델을 제공하는 마지막 구성을 삭제하면 항목도 사라집니다. 대응하는 구성이 없는 이름은 표시되지 않습니다.
- 기본 모델 항목을 Relay를 통해 외부 공급자로 전달해도 대화는 이어갈 수 있지만 암호화된 추론 내용은 제거됩니다. 외부 공급자는 추론 요약과 텍스트를 받습니다. OpenAI가 암호화한 내용은 OpenAI만 읽을 수 있습니다. 암호화된 추론 연결을 유지하려면 주소가 `api.openai.com`이고 본인의 OpenAI 키를 사용하는 채널을 설정하세요.
- 세션 이어가기는 선택한 세션의 연결 구성만 변경하며 과거 대화 내용을 다시 쓰지 않습니다. 작업 전에 안내에 따라 Codex를 정상 종료하세요.
- 양방향 전환 절차는 같습니다. Codex 데스크톱 앱과 명령줄 프로그램을 종료하고 세션과 대상을 선택한 다음 적용합니다. Codex가 실행 중이거나 로그인되어 있을 필요는 없으며 Relay가 켜져 있을 필요도 없습니다. Relay 연결로 전환하려면 먼저 모델 구성을 저장해야 합니다.
- 공식 연결로 되돌릴 때는 가장 최근의 사용 가능한 적합한 공식 세션 모델을 우선 참조합니다. 없으면 해당 세션의 원래 공식 메타데이터 백업을 사용합니다. 둘 다 신뢰할 수 있는 출처가 없으면 전환을 중단합니다.
- 전환 후 Relay 연결은 Relay를 먼저 켠 다음 Codex를 시작하고, 공식 연결은 Relay를 먼저 끈 다음 Codex를 시작합니다. 공식 서비스를 이용할 때 Codex가 로그인을 다시 요구할 수 있습니다.

## 자주 묻는 질문

### 모델이 없나요?

새 설치에는 미리 설정된 모델이 없습니다. 자신의 공급자와 모델을 추가하세요. 사용 가능한 모델을 가져올 때 여러 모델을 선택할 수 있으며 각각 별도의 구성으로 저장됩니다.

### 요청이 실패하나요?

주소, API 키, 잔액, 모델 이름을 확인하세요. 문제를 제보할 때 키나 대화 본문을 보내지 마세요.

### Token 통계는 어디에서 가져오나요?

원래 요청에 대한 상위 공급자 응답의 사용량 정보를 이용합니다. 표시 위치마다 별도의 요청을 보내지 않습니다.

### Trip Token A/B는 어떻게 사용하나요?

A와 B는 독립된 소계입니다. 각자 초기화한 시점부터 선택한 범위를 집계합니다. 날짜가 바뀌거나 앱을 다시 시작해도 계속되며 해당 열의 초기화만 소계를 재설정합니다. 초기화해도 오늘의 합계와 요청 로그는 바뀌지 않고 이전 구간은 이동 기록에 보관됩니다. 서로 다른 작업을 기록하고 이름을 붙일 수 있습니다. 실패한 요청도 요청 횟수에 포함되며 Token은 공급자가 반환한 사용량으로 집계합니다.

### 날짜 필터는 어떻게 사용하나요?

날짜와 일, 주, 월, 분기, 연도 기간을 선택하여 해당 범위를 확인합니다. 오류 비율의 분모는 선택한 기간의 전체 요청 수입니다.

### 익명 통계 동의는 어떻게 처리되나요?

설치 화면에서는 동의와 거부 중 어느 것도 미리 선택하지 않습니다. 참여 여부를 한 번 선택하면 계속할 수 있습니다. 이 선택은 로컬 익명 통계와 업로드 권한을 함께 제어하며 추가 확인은 없습니다. 거부해도 설치와 사용에 영향이 없으며 나중에 설정에서 변경할 수 있습니다. 새 무인 설치는 기본적으로 꺼져 있고 무인 업그레이드는 기존 동의를 유지합니다. 업로드는 정상 종료할 때만 시도하며 실패하면 다음 종료 때 다시 시도합니다. 전체 항목과 저장 방식은 개인정보 처리방침을 참고하세요.

### 어떻게 업데이트하나요?

자동 업데이트 확인을 켜면 Relay가 시작 후와 24시간마다 백그라운드에서 확인합니다. GitHub를 기본 출처로 사용하고 공식 웹사이트를 보조 출처로 사용합니다. 새 설치 파일을 자동으로 다운로드하고 크기와 SHA256을 검증합니다. 설정에서 업데이트 설치를 눌러 설치 프로그램을 열고 설치 전에 Relay를 정상 종료하세요. 설치 프로그램은 자동 실행되지 않습니다. 지금 확인을 눌러 수동으로 확인할 수도 있습니다.

### 데이터와 제거

설정에 데이터 디렉터리가 표시됩니다. 앱을 제거해도 사용자 데이터는 유지됩니다. 삭제하려면 Relay를 정상 종료하고 필요한 내용을 백업한 다음 해당 데이터 디렉터리만 처리하세요. Codex 디렉터리는 삭제하지 마세요.
