# MicroGlow Relay 使用說明

## 接入

1. 在「模型」頁填入供應商介面位址、API Key，並新增模型。
2. 正常結束 Codex 桌面版及命令列，開啟 Relay，等待服務就緒，依提示啟用 Codex 接入。
3. 重新啟動 Codex。Claude Code 請使用對應的接入開關，依提示操作。

關閉 Relay 或正常結束程式會恢復原生 Codex 接入。縮到系統匣不等於結束，請使用系統匣選單的結束命令。

請先結束 Codex / Claude Code，再結束 Relay，接入設定會自動還原。若還原失敗，Relay 會保持執行並顯示原因；處理後再次結束即可。

## 模型與工作階段

- 在 Codex 工作階段內按需選擇模型；預設模型在「模型」頁設定。該頁支援新增、編輯、搜尋、刪除設定，以及為同一模型新增多個通道。
- 設定中的模型名稱與 Codex 原生模型名稱完全相同時，對應項目會出現在 Codex 模型選擇器中。例如儲存模型名稱為 `gpt-6-astra` 的設定後，該項目會出現；刪除最後一筆提供該模型的設定後，項目消失。沒有對應設定的名稱不會列出。
- 原生項目經 Relay 轉送至第三方介面時可繼續對話，但加密推理內容會被移除，第三方收到的是推理摘要與文字。OpenAI 的加密內容只有 OpenAI 能讀取。若需保留加密推理鏈，請使用介面為 `api.openai.com`、設定您本人 OpenAI 金鑰的通道。
- 工作階段接續只調整所選工作階段的接入設定，不改寫歷史對話。操作前請依提示正常結束 Codex。
- 雙向切換的步驟一致：結束 Codex 桌面版及命令列，選擇工作階段與目標，然後套用。不要求 Codex 正在執行或已登入，也不要求 Relay 已開啟；轉入 Relay 前需儲存模型設定。
- 轉回官方接入時，優先參考最近可用的官方工作階段模型；沒有參考時，使用該工作階段原始官方中繼資料備份。兩者皆無可靠來源時，轉換停止。
- 轉換後，Relay 接入需先開啟 Relay 再啟動 Codex；官方接入需先關閉 Relay 再啟動 Codex。使用官方服務時，Codex 仍可能要求登入。

## 常見問題

### 沒有模型？

首次安裝沒有預設模型。請新增自己的供應商及模型；「取得可用模型」支援多選，每個模型儲存為一筆設定。

### 請求失敗？

檢查介面位址、金鑰、餘額及模型名稱。回報問題時請勿傳送金鑰或對話正文。

### Token 統計從哪裡來？

來自原請求上游回應中的用量資訊，不會為不同顯示位置重複請求。

### 如何使用 Trip Token A/B？

A、B 是兩段獨立小計，從各自的歸零時間開始，依所選範圍統計。跨日不歸零，重新啟動後繼續，只有該欄的「歸零」會重設。歸零不會變更今日總量與請求日誌，會將原區間存入行程記錄。可分別記錄兩個任務並命名。失敗請求仍計入請求次數；Token 依上游回傳的用量統計。

### 如何篩選日期？

選擇日期及日、週、月、季、年週期，查看對應時間範圍的資料。錯誤比例的分母是所選範圍的總請求數。

### 如何授權匿名統計？

安裝頁的兩個授權選項皆不預選，主動選擇同意加入或不同意加入一次後繼續。選擇同時控制本機匿名統計與上傳授權，不重複確認；拒絕不影響安裝和使用，可在設定中變更。首次無訊息安裝預設關閉，無訊息升級保留已有授權。僅在正常結束時嘗試上傳，失敗後下次結束時重試。完整欄位與儲存行為請見隱私政策。

### 如何更新？

啟用自動檢查更新時，Relay 在啟動後及每 24 小時於背景檢查，優先使用 GitHub，官網作為備用來源。新安裝套件會自動下載並驗證大小及 SHA256。點擊設定中的「安裝更新」開啟安裝程式，安裝前請正常結束 Relay。安裝程式不會自動執行；也可點擊「立即檢查」手動檢查。

### 資料與解除安裝

設定頁顯示資料目錄，解除安裝會保留使用者資料。如需清理，請先正常結束 Relay，備份需要保留的內容，再處理該資料目錄。請勿刪除 Codex 目錄。
