# MicroGlow Relay 使い方

## 接続

1. 「モデル」ページでプロバイダーの接続先、API キーを入力し、モデルを追加します。
2. Codex のデスクトップ版とコマンドライン版を通常の手順で終了します。Relay を有効にし、サービスの準備が完了したら、画面の案内に従って Codex 接続を有効にします。
3. Codex を起動し直します。Claude Code は対応する接続スイッチを使用し、画面の案内に従ってください。

Relay を無効にするか通常終了すると、Codex 本来の接続に戻ります。トレイへの最小化は終了ではありません。トレイメニューの終了コマンドを使用してください。

先に Codex / Claude Code を終了し、その後 Relay を終了してください。Relay は終了前に接続設定を復元します。復元に失敗した場合は終了せず、理由を表示します。問題を解決してから再度終了してください。

## モデルとセッション

- Codex のセッション内で必要なモデルを選択します。既定のモデルは「モデル」ページで設定します。同ページでは設定の追加、編集、検索、削除と、同じモデルへの複数チャネルの追加ができます。
- 保存したモデル名が Codex のネイティブモデル名と完全に一致すると、対応する項目が Codex のモデル選択に表示されます。たとえば `gpt-6-astra` というモデル名の設定を保存すると、その項目が表示されます。そのモデルを提供する最後の設定を削除すると項目も消えます。対応する設定がない名前は表示されません。
- ネイティブモデルの項目を Relay 経由で第三者の接続先へ転送しても会話は継続できますが、暗号化された推論内容は除去されます。第三者には推論の要約とテキストが渡されます。OpenAI の暗号化内容を読めるのは OpenAI だけです。暗号化された推論の連鎖を保持するには、接続先が `api.openai.com` で、ご自身の OpenAI キーを設定したチャネルを使用してください。
- セッションの継続機能は選択したセッションの接続設定だけを変更し、過去の会話を書き換えません。操作前に案内に従って Codex を通常終了してください。
- どちらの方向への変換も、Codex のデスクトップ版とコマンドライン版を終了し、セッションと変換先を選択して適用します。Codex の起動やログイン、Relay の有効化は不要です。Relay 接続への変換前にはモデル設定を保存しておく必要があります。
- 公式接続へ戻す場合、利用可能な最新の適格な公式セッションモデルを優先します。参照先がない場合は、そのセッションの元の公式メタデータのバックアップを使用します。どちらも信頼できる情報源がない場合、変換は停止します。
- 変換後、Relay 接続では Relay を有効にしてから Codex を起動し、公式接続では Relay を無効にしてから Codex を起動します。公式サービスの利用時には、Codex が再ログインを求める場合があります。

## よくある質問

### モデルが表示されません

新規インストールには設定済みのモデルはありません。ご自身のプロバイダーとモデルを追加してください。利用可能なモデルの取得では複数を選択でき、それぞれが個別の設定として保存されます。

### リクエストが失敗します

接続先、API キー、残高、モデル名を確認してください。問い合わせにはキーや会話本文を含めないでください。

### Token 統計はどこから取得しますか

元のリクエストに対する上流の応答に含まれる使用量情報を使用します。表示箇所ごとに追加リクエストを送ることはありません。

### Trip Token A/B はどう使いますか

A と B は独立した小計です。それぞれのリセット時刻から、選択した範囲を集計します。日付をまたいでもアプリを再起動しても継続し、その欄のリセット操作だけで初期化されます。リセットしても当日の合計とリクエストログは変わらず、それまでの区間は行程履歴に保存されます。別々の作業を記録し、名前を付けることもできます。失敗したリクエストも件数に含まれ、Token は上流から報告された使用量で集計します。

### 日付で絞り込むには

日付と、日・週・月・四半期・年の期間を選び、対応する範囲を表示します。エラー率の分母は、選択範囲内の総リクエスト数です。

### 匿名統計への同意について

インストール時の同意・不同意の選択肢は、どちらも事前選択されていません。参加するかどうかを一度選んで続行します。この選択でローカルの匿名統計と送信許可の両方を設定し、二重の確認はありません。拒否してもインストールや利用に影響せず、後から設定で変更できます。新規のサイレントインストールでは無効、サイレント更新では既存の同意を保持します。送信は通常終了時だけ試み、失敗した場合は次回終了時に再試行します。全項目と保存方法はプライバシーポリシーを参照してください。

### 更新するには

自動更新確認を有効にすると、Relay は起動後と 24 時間ごとにバックグラウンドで確認します。GitHub を優先し、公式サイトを予備の取得元として使用します。新しいインストーラーを自動ダウンロードし、サイズと SHA256 を検証します。設定の「更新をインストール」を押してインストーラーを開き、インストール前に Relay を通常終了してください。インストーラーが自動実行されることはありません。「今すぐ確認」で手動確認もできます。

### データとアンインストール

設定にデータフォルダーが表示されます。アンインストールしてもユーザーデータは残ります。削除する場合は Relay を通常終了し、必要な内容をバックアップしたうえで、そのデータフォルダーだけを処理してください。Codex のフォルダーは削除しないでください。
