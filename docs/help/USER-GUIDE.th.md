# คู่มือการใช้ MicroGlow Relay

## การเชื่อมต่อ

1. ในหน้าโมเดล ให้กรอกที่อยู่ของผู้ให้บริการและคีย์ API แล้วเพิ่มโมเดล
2. ออกจาก Codex ทั้งแอปเดสก์ท็อปและโปรแกรมบรรทัดคำสั่งตามปกติ เปิด Relay รอให้บริการพร้อม แล้วทำตามคำแนะนำเพื่อเปิดการเชื่อมต่อ Codex
3. เปิด Codex อีกครั้ง สำหรับ Claude Code ให้ใช้สวิตช์การเชื่อมต่อของโปรแกรมนั้นและทำตามคำแนะนำบนหน้าจอ

การปิด Relay หรือออกจากโปรแกรมตามปกติจะคืนค่าการเชื่อมต่อเดิมของ Codex การย่อไปยังถาดระบบไม่ใช่การออกจากโปรแกรม ให้ใช้คำสั่งออกจากเมนูในถาดระบบ

ออกจาก Codex / Claude Code ก่อน แล้วจึงออกจาก Relay โดย Relay จะคืนค่าการเชื่อมต่อก่อนออก หากคืนค่าไม่สำเร็จ Relay จะยังทำงานและแสดงสาเหตุ ให้แก้ไขปัญหาแล้วลองออกอีกครั้ง

## โมเดลและเซสชัน

- เลือกโมเดลที่ต้องการภายในเซสชัน Codex และตั้งค่าโมเดลเริ่มต้นในหน้าโมเดล หน้านี้รองรับการเพิ่ม แก้ไข ค้นหา และลบการตั้งค่า รวมถึงเพิ่มหลายช่องทางให้โมเดลเดียวกัน
- หากชื่อโมเดลที่บันทึกตรงกับชื่อโมเดลเดิมของ Codex ทุกตัวอักษร รายการนั้นจะแสดงในตัวเลือกโมเดลของ Codex เช่น เมื่อบันทึกการตั้งค่าชื่อ `gpt-6-astra` รายการนั้นจะปรากฏ และจะหายไปเมื่อลบการตั้งค่าสุดท้ายที่ให้บริการโมเดลนี้ ชื่อที่ไม่มีการตั้งค่ารองรับจะไม่แสดง
- รายการโมเดลเดิมที่ส่งผ่าน Relay ไปยังผู้ให้บริการภายนอกยังสนทนาต่อได้ แต่เนื้อหาการให้เหตุผลที่เข้ารหัสจะถูกนำออก ผู้ให้บริการภายนอกจะได้รับบทสรุปการให้เหตุผลและข้อความ เฉพาะ OpenAI เท่านั้นที่อ่านเนื้อหาซึ่ง OpenAI เข้ารหัสได้ หากต้องการรักษาสายการให้เหตุผลที่เข้ารหัส ให้ใช้ช่องทางที่มีที่อยู่ `api.openai.com` และคีย์ OpenAI ของคุณเอง
- การต่อเซสชันเปลี่ยนเฉพาะการตั้งค่าการเชื่อมต่อของเซสชันที่เลือก ไม่เขียนประวัติการสนทนาใหม่ ก่อนทำรายการให้ออกจาก Codex ตามปกติตามคำแนะนำ
- การแปลงทั้งสองทิศทางใช้ขั้นตอนเดียวกัน คือออกจาก Codex ทั้งเดสก์ท็อปและบรรทัดคำสั่ง เลือกเซสชันกับปลายทาง แล้วใช้การเปลี่ยนแปลง ไม่จำเป็นต้องเปิด Codex หรือลงชื่อเข้าใช้ และไม่จำเป็นต้องเปิด Relay แต่ต้องบันทึกการตั้งค่าโมเดลก่อนแปลงไปใช้ Relay
- เมื่อแปลงกลับไปใช้การเชื่อมต่ออย่างเป็นทางการ ระบบจะใช้โมเดลเซสชันทางการล่าสุดที่มีคุณสมบัติเหมาะสมก่อน หากไม่มี จะใช้ข้อมูลเมตาทางการดั้งเดิมที่สำรองไว้ของเซสชันนั้น หากทั้งสองแหล่งไม่น่าเชื่อถือ การแปลงจะหยุด
- หลังแปลง หากใช้ Relay ให้เปิด Relay ก่อนเริ่ม Codex หากใช้การเชื่อมต่อทางการ ให้ปิด Relay ก่อนเริ่ม Codex การใช้บริการทางการอาจยังต้องลงชื่อเข้าใช้ Codex

## คำถามที่พบบ่อย

### ไม่มีโมเดลใช่ไหม

การติดตั้งใหม่ไม่มีโมเดลที่ตั้งค่าไว้ล่วงหน้า ให้เพิ่มผู้ให้บริการและโมเดลของคุณเอง การดึงรายชื่อโมเดลที่ใช้ได้รองรับการเลือกหลายรายการ โดยแต่ละโมเดลจะถูกบันทึกเป็นการตั้งค่าแยกกัน

### คำขอล้มเหลวใช่ไหม

ตรวจสอบที่อยู่ คีย์ API ยอดคงเหลือ และชื่อโมเดล อย่าส่งคีย์หรือเนื้อหาการสนทนาเมื่อรายงานปัญหา

### สถิติ Token มาจากไหน

มาจากข้อมูลการใช้งานในคำตอบของผู้ให้บริการต่อคำขอเดิม Relay ไม่ส่งคำขอเพิ่มเพื่อแสดงสถิติในแต่ละตำแหน่ง

### ใช้ Trip Token A/B อย่างไร

A และ B เป็นยอดย่อยอิสระ แต่ละยอดเริ่มนับจากเวลารีเซ็ตของตนเองตามขอบเขตที่เลือก นับต่อข้ามวันและหลังเปิดโปรแกรมใหม่ มีเพียงการรีเซ็ตในคอลัมน์นั้นที่เริ่มยอดใหม่ การรีเซ็ตไม่เปลี่ยนยอดรวมวันนี้หรือบันทึกคำขอ และจะเก็บช่วงก่อนหน้าไว้ในประวัติการเดินทาง ใช้แยกงานสองงานและตั้งชื่อได้ คำขอที่ล้มเหลวยังนับเป็นจำนวนคำขอ ส่วน Token นับตามการใช้งานที่ผู้ให้บริการส่งกลับ

### ใช้ตัวกรองวันที่อย่างไร

เลือกวันที่และช่วงวัน สัปดาห์ เดือน ไตรมาส หรือปี เพื่อดูข้อมูลในช่วงที่สอดคล้องกัน ตัวหารของอัตราข้อผิดพลาดคือจำนวนคำขอทั้งหมดในช่วงที่เลือก

### การยินยอมสถิติแบบไม่ระบุตัวตนทำงานอย่างไร

ระหว่างติดตั้งจะไม่เลือกตัวเลือกยินยอมหรือไม่ยินยอมไว้ล่วงหน้า ให้เลือกเข้าร่วมหรือปฏิเสธหนึ่งครั้งเพื่อดำเนินการต่อ ตัวเลือกนี้ควบคุมทั้งสถิติแบบไม่ระบุตัวตนในเครื่องและสิทธิ์อัปโหลด โดยไม่มีการยืนยันซ้ำ การปฏิเสธไม่กระทบการติดตั้งหรือการใช้งาน และเปลี่ยนภายหลังได้ในการตั้งค่า การติดตั้งใหม่แบบเงียบจะปิดไว้ ส่วนการอัปเกรดแบบเงียบรักษาความยินยอมเดิม จะลองอัปโหลดเฉพาะเมื่อออกตามปกติ หากล้มเหลวจะลองใหม่เมื่อออกครั้งถัดไป ดูรายการข้อมูลและวิธีจัดเก็บทั้งหมดในนโยบายความเป็นส่วนตัว

### อัปเดตอย่างไร

เมื่อเปิดการตรวจสอบอัปเดตอัตโนมัติ Relay จะตรวจสอบเบื้องหลังหลังเริ่มโปรแกรมและทุก 24 ชั่วโมง โดยใช้ GitHub เป็นแหล่งหลักและเว็บไซต์ทางการเป็นแหล่งสำรอง ตัวติดตั้งใหม่จะดาวน์โหลดอัตโนมัติและตรวจสอบขนาดกับ SHA256 กดติดตั้งอัปเดตในการตั้งค่าเพื่อเปิดตัวติดตั้ง และออกจาก Relay ตามปกติก่อนติดตั้ง ตัวติดตั้งจะไม่ทำงานเองโดยอัตโนมัติ คุณยังสามารถกดตรวจสอบตอนนี้เพื่อตรวจสอบด้วยตนเองได้

### ข้อมูลและการถอนการติดตั้ง

หน้าการตั้งค่าจะแสดงโฟลเดอร์ข้อมูล การถอนการติดตั้งจะเก็บข้อมูลผู้ใช้ไว้ หากต้องการลบ ให้ออกจาก Relay ตามปกติ สำรองเนื้อหาที่ต้องการเก็บ แล้วจัดการเฉพาะโฟลเดอร์ข้อมูลนั้น อย่าลบโฟลเดอร์ Codex
